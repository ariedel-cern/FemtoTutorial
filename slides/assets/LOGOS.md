# Logo sources

- ALICE emblem currently used: https://alice.cern/wp-content/uploads/2026/10/alice-favicon-Color_Logo_DB-300x300.png (official ALICE website). This text-free emblem is displayed directly on the white slide background.
- Earlier ALICE logo with lettering, retained as an unused asset: https://alice-collaboration.web.cern.ch/sites/default/files/logo/ALICE_Color_Logo_small_0_0.png.
- TUM: https://www.tum.de/typo3conf/ext/in2template/Resources/Public/Images/Backend/tum-logo.svg (official TUM website). The vector shape is preserved, with the white fill changed to TUM blue (`#0065BD`) for the white slide background. `tum-logo.pdf` is generated from this SVG using `rsvg-convert`.

Assets are stored locally so rebuilding the deck does not require network access.
